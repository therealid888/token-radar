# Protocol Category Chains TVL 7d Age Implied value

How the value is computed

Implied value = TVL × category ratio × growth factor × age factor. The category ratio is the median mcap/TVL of the token-bearing protocols in that category in this snapshot — the calibration the snapshot itself provides, never a hardcoded list of names. A category with fewer than three token-bearing protocols with a market cap falls back to the global median. The growth factor moves with the protocol’s 7-day TVL change (clamped to −50%…+200%, half weight). The age factor grows with how long the protocol has run with no token recorded, from its first DefiLlama listing to the snapshot date, capped at 1.5×. The result is the radar’s own claim from the snapshot’s figures — not a prediction that a token will be issued, or when, and not a promise of any reward.

144 wrapped, staked or bridged products of a token that already trades (or versioned products of one) are left off this board entirely, judged by the same rule the snapshot’s watchlist uses to leave such protocols out: a Bridge, Canonical Bridge, Liquid Staking, Liquid Restaking, Restaked BTC or CEX category, a name carrying a whole word wrapped, staked or staking, a name beginning with an exchange’s name, or a version suffix. Their token already trades in another form, so they are not fresh launch candidates. The watchlist is the floor, never the ceiling: this board ranks the 198 protocols that record no token and are not such a product.

Data: DefiLlama protocols snapshot, fetched 2026-11-14. A protocol is listed as “records no token” when DefiLlama records no token for it; that is the record, not proof it has none. Farm steps are actions a reader can take on the protocol itself; none of them promises a token, an airdrop, or a reward.
